# 📖 About

**Math Lab JS** is a collection of JavaScript programs that solve various mathematical problems, ranging from basic arithmetic to interesting number theory concepts.

The purpose of this repository is to improve:

- 🧠 Logical Thinking
- ⚡ Problem-Solving Skills
- 📚 Mathematical Concepts
- 💻 JavaScript Programming

Every problem is implemented with readability and simplicity in mind, making this repository useful for beginners as well as those preparing for coding interviews.

---

# ✨ Features

- 📌 30+ mathematical problems
- 📖 Clean and beginner-friendly code
- ⚡ Optimized solutions wherever applicable
- 🧩 Covers multiple categories of mathematics
- 🚀 Easy to run using Node.js
- 📚 Great for learning JavaScript logic building

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/devKartikeya/Math-Lab-JS.git
```

## Navigate into the Project

```bash
cd Math-Lab-JS
```

## Run any Program

```bash
node filename.js
```

Example:

```bash
node Armstrong_Number.js
```
